# Sistema de Votaciones

Aplicacion web para la gestion de votaciones, desarrollada con Python y Flask.

## Caracteristicas

- Registro de votantes y candidatos.
- Emision y conteo de votos.
- Persistencia en base de datos MySQL.

## Tecnologias

Python, Flask, MySQL.

## Ejecucion

```bash
pip install -r requirements.txt
python app.py
```
